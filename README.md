# MediBook - სამედიცინო ვიზიტების მართვის სისტემა

**Live Demo:** [https://medibook-project1.vercel.app](https://medibook-project1.vercel.app)
**კატეგორია:** სამედიცინო ჰაბი

---

## 1. პროექტის შესახებ

**MediBook** არის React-ზე დაფუძნებული თანამედროვე ვებ-აპლიკაცია, რომელიც უზრუნველყოფს პაციენტებისთვის ექიმის მოძიებისა და ვიზიტის დაჯავშნის პროცესის მაქსიმალურ გამარტივებას ბიუროკრატიული ბარიერების გარეშე. პლატფორმა საშუალებას აძლევს მომხმარებლებს, რეალურ დროში დაინახონ ექიმების თავისუფალი სლოტები და მომენტალურად დაჯავშნონ ვიზიტი.

## 2. ძირითადი ფუნქციონალი (Key Features)

- **მონაცემთა მართვა (CRUD & State):** ვიზიტების დამატება, სიის წაკითხვა და გაუქმება პირდაპირ `LocalStorage`-ში სინქრონიზაციით, რაც იცავს მონაცემებს დარეფრეშებისას.
- **ძიება და ფილტრაცია:** ოპტიმიზებული ცოცხალი ძიება `useDebounce` ჰუკით (300ms) და სპეციალობების მიხედვით სწრაფი ფილტრაცია.
- **მოდალური ფანჯრები და ვალიდაცია:** იზოლირებული მოდალები `ReactDOM.createPortal`-ის მეშვეობით (z-index კონფლიქტების გარეშე) და ფორმის მკაცრი ვალიდაცია (Double-click ბლოკირებით).
- **მდგრადობა (Resilience):** სისტემის დაცვა რანთაიმ შეცდომებისგან `ErrorBoundary` კომპონენტით (თეთრი ეკრანის პრევენცია).
- **Responsive დიზაინი:** სრული ადაპტურობა (Mobile-First მიდგომა) მობილურ, პლანშეტურ და დესკტოპ ეკრანებზე Tailwind CSS-ის გრიდებით.

## 3. ტექნოლოგიური სტეკი

| კატეგორია | გამოყენებული ტექნოლოგია |
| :--- | :--- |
| **Core** | React 19, Vite, TypeScript |
| **State Management** | LocalStorage API (კომპონენტის ლოკალურ სთეითთან ერთად) |
| **Styling & UI** | Tailwind CSS v4, CSS Variables |
| **Icons & Media** | Lucide React (SVG) |

## 4. პროექტის სტრუქტურა

```text
src/
 ├── components/    # იზოლირებული UI კომპონენტები (Modal, BookingForm, ErrorBoundary)
 ├── hooks/         # Custom ჰუკები (მაგ. useDebounce)
 ├── data/          # ექიმების სტატიკური მონაცემთა ბაზა (Mock Data)
 └── types/         # TypeScript-ის ინტერფეისები და მოდელები
```

## 5. ლოკალურად გაშვების ინსტრუქცია

პროექტის საკუთარ კომპიუტერზე გასაშვებად, მიჰყევით შემდეგ ნაბიჯებს:

1. **დააკლონირეთ რეპოზიტორია:**
   ```bash
   git clone https://github.com/neekall/medibook.git
   cd medibook
   ```

2. **დააყენეთ პაკეტები (Dependencies):**
   ```bash
   npm install
   ```

3. **გაუშვით დეველოპერული სერვერი:**
   ```bash
   npm run dev
   ```
   *აპლიკაცია გაიხსნება მისამართზე: `http://localhost:5173`*

## 6. სატესტო ანგარიშები

სისტემა ამ ეტაპზე მორგებულია პაციენტის თავისუფალ ნაკადზე და **არ მოითხოვს ავტორიზაციას**. ნებისმიერ მომხმარებელს შეუძლია ექიმის მოძიება და ვიზიტის დაჯავშნა პირადი მონაცემების მითითებით.

## 7. ხელმისაწვდომი სკრიპტები

- `npm run dev` - დეველოპერული სერვერის გაშვება ლოკალურად.
- `npm run build` - ოპტიმიზებული საწარმოო (Production) ბანდლის აწყობა.
- `npm run preview` - აწყობილი Production ვერსიის ლოკალურად შემოწმება.
- `npm run lint` - კოდის ხარისხისა და სისუფთავის შემოწმება ESLint-ით.
