# MediBook - სამედიცინო ჯავშნების სისტემა

**MediBook** არის თანამედროვე, სწრაფი და მოსახერხებელი სამედიცინო ვიზიტების დაჯავშნის ვებ-აპლიკაცია. პლატფორმა საშუალებას აძლევს მომხმარებლებს მოიძიონ სასურველი ექიმები სპეციალობის მიხედვით, გაეცნონ მათ რეიტინგსა და გამოცდილებას, აირჩიონ ხელსაყრელი დრო და მარტივად მართონ საკუთარი ჯავშნები.

---

## 🚀 ტექნოლოგიური სტეკი (Tech Stack)

- **Frontend ბიბლიოთეკა**: [React 19](https://react.dev/)
- **პროგრამირების ენა**: [TypeScript](https://www.typescriptlang.org/) (Strict typing, `verbatimModuleSyntax`)
- **სტილიზაცია**: [Tailwind CSS v4](https://tailwindcss.com/)
- **აიკონები**: [Lucide React](https://lucide.dev/)
- **ბილდერი და დეველოპმენტ სერვერი**: [Vite](https://vite.dev/)

---

## 🌟 ძირითადი ფუნქციონალი და არქიტექტურა

1. **ექიმების კატალოგი და დინამიკური ფილტრაცია**
   - ექიმების სია დეტალური ინფორმაციით (სახელი, სპეციალობა, რეიტინგი, სამუშაო გამოცდილება, ხელმისაწვდომი საათები).
   - კატეგორიების/სპეციალობის მიხედვით მყისიერი ფილტრაცია `useMemo` ოპტიმიზაციით.

2. **ოპტიმიზებული ძიება (`useDebounce`)**
   - რეალურ დროში ძიება ექიმის სახელისა და სპეციალობის მიხედვით.
   - შექმნილია `useDebounce` Custom Hook-ი, რომელიც ამცირებს არასაჭირო გადარენდერებებს (300ms დილეი).

3. **მოდალური ფანჯარა (`React Portals`)**
   - `Modal` კომპონენტი იყენებს `createPortal`-ს `document.body`-ზე დასარენდერებლად, რაც გამორიცხავს მშობელი ელემენტების `z-index` ან `overflow: hidden` შეზღუდვებს.
   - მხარდაჭერილია კლავიატურის `Escape` ღილაკით დახურვა და ფონის სქროლის ავტომატური ბლოკირება მოდალის გახსნისას.

4. **ფორმა და ვალიდაცია (`BookingForm`)**
   - ველების ვალიდაცია: პაციენტის სახელი, ტელეფონის ნომერი, თარიღი და ექიმის მიერ განსაზღვრული ხელმისაწვდომი საათის არჩევა.
   - დაცვა ცარიელი ან არასწორი მონაცემების გაგზავნისგან მომხმარებლისთვის გასაგები შეტყობინებით.

5. **მონაცემთა შენახვა (`localStorage Persistence`)**
   - დადასტურებული ჯავშნები ინახება ბრაუზერის `localStorage`-ში (`medibook_appointments`), რაც უზრუნველყოფს მონაცემების შენარჩუნებას გვერდის გადატვირთვის შემდეგაც.
   - სრული CRUD მხარდაჭერა: ახალი ჯავშნის დამატება, აქტიური ჯავშნების სია და გაუქმება/წაშლა.

6. **შეცდომების დამუშავება (`ErrorBoundary`)**
   - კლასობრივი `ErrorBoundary` კომპონენტი, რომელიც იჭერს რენდერის დროს წარმოქმნილ შეცდომებს და მომხმარებელს აწვდის Fallback UI-ს აპლიკაციის სრული გათიშვის გარეშე.

## 🛠️ ლოკალური გაშვების ინსტრუქცია (Local Setup)

### წინაპირობები
- [Node.js](https://nodejs.org/) (ვერსია 18.0 ან უფრო ახალი)
- `npm`, `yarn` ან `pnpm`

### ინსტალაციის ნაბიჯები

1. **დამოკიდებულებების ინსტალაცია:**
   ```bash
   npm install
   ```

2. **დეველოპმენტ სერვერის გაშვება:**
   ```bash
   npm run dev
   ```
   აპლიკაცია გაეშვება მისამართზე: `http://localhost:5173/`

3. **TypeScript ტიპების შემოწმება:**
   ```bash
   npx tsc -b
   ```

4. **ESLint ლინტინგი:**
   ```bash
   npm run lint
   ```

5. **საპროდაქშენო ბილდის აწყობა:**
   ```bash
   npm run build
   ```
